# UNT Group Finder

This project is split into three files: `index.html`, `style.css`, and `script.js`. Keep all three files in the same folder and open `index.html`.

The login and registration screens are centered and compact to avoid the previous display/layout issue. The Account section includes demo password updating and account verification.

**Important:** This is a front-end demo only. Password changes and verification are kept in page memory, are not saved to a server, and verification does not send an email.


Latest fix: login and registration screens are hidden unless active, preventing the registration form from appearing below the login page and creating unwanted page scrolling.
